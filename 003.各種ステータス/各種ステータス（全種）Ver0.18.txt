0. Ver.0.18 変更点（対 Ver.0.17）
================================================================================
1) 全ボタン・入力枠・リスト行の高さを 0.6cm 削減
   - 基準: min-height/height の 44px → calc(44px - 0.6cm)
   - 丸ボタン 32px系・復帰ボタン 48px系・リスト行 50px系なども同様に -0.6cm
   - 付随する ▲▼ ステップボタン高さも親入力に合わせて縮小
   - チェックボックス(20px)・プレビューラベル上の微小ハンドル(18px)は維持

2) ステータス設定の高さ／幅入力行
   - 単位「cm」と上下増減ボタンが枠幅内に収まるよう
     .dimension-row を width:calc(100cqw - 20px) でステータス表示幅に拘束

3) ラベル「数値」の単位入力 #labelUnit
   - 幅 100px → 50px（半分）

4) ステータス設定内の pt 表示枠を 1.3cm に統一
   - #strokeWidth / #leaderStrokeWidth / input[data-size]

5) ステータス設定内ボタン「棒色」「枠色」「色」の幅を 1.3cm に固定
   - #barColor / #borderColor / #leaderColor

6) 引き出し線の色・サイズ行と上行の間隔を 0.3cm
   - .leader-color-row { margin-top:0.3cm }

7) カード保存ボタンと上行の間隔を 0.6cm
   - #saveCard { margin-top:0.6cm }

【追記 2026-11-02】追加修正
A) 丸型ボタン（.round-control / 復帰ボタン48px）と色スウォッチ（.color-swatch 32px、large 48px）を Ver.0.17 サイズへ復帰
B) ステータス設定内の数値・単位入力欄の高さを上記に合わせ 32px に統一
   （#barHeight/#barWidth、#strokeWidth/#leaderStrokeWidth、ラベル数値・単位・文字サイズ、データ欄 など）
C) #previewOnlyStatus（ON/OFF枠）を #previewOnly と同じ行高に（.preview-actions を stretch 整列）
D) 三点リーダー（.asset-project-drag / .label-drag）は display:flex + align-items:center でアイコンを上下中央配置

■全体レイアウト（#app.app）
--------------------------------------------------------------------------------
位置・サイズ:
  - 画面全体（height: 100dvh、min-height: 800px〜1000px）
  - 通常時グリッド行: タイトルバー(約4fr) / 復帰ドック(60px固定) / 作業領域(約29fr) / アセット枠(約15fr)
  - 通常時グリッド列: 可変（--asset-columns）。基準は左枠群 1fr × N + 中央(プレビュー等) 残りfr + 右データ枠 1fr
  - 列は表示中の左パネル数に応じてJS(syncAssetColumns)が動的割当
      例) アセット編集のみ: 1fr | 6fr | 1fr
      例) +設定: 1fr | 1fr | 5fr | 1fr
      例) +棒設定: 1fr | 1fr | 1fr | 4fr | 1fr
  - プレビューのみ表示時(.preview-only): 列は1列、行はタイトル/ドック/プレビュー中心

用途:
  - アプリ全体の骨格。各パネルの表示・折りたたみに応じて列構成を再計算
